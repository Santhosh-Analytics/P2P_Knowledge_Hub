# Variance Reduction

Variance Reduction measures how much splitting reduces the overall variance.

The formula for variance (mean squared error):

    $\text{Variance} = \frac{1}{n}\sum_{i=1}^n\left (y_i - \bar{y}\right)^2$

Where,

- $\frac{1}{n}$ - n is number of data points
- $y_i$ - is Target variable
- $\bar{y}$ - Mean of Target variable

Example:

![](Pasted%20image%2020250123011439.png)

The formula for _Variance Reduction_ is:

    $\text{Variance Reduction} = \text{var}\left(\text{root}\right) - \sum{w_i}\text{var}\left(\text{child}\right)$

Where,

- $\text{var}\left(\text{root}\right)$ - Variance of root node
- $\sum{w_i}$ - Weight of the child node. $w_i=\frac{\text{size of child}}{\text{size of root}}$
  - If root has 5 data point and child as one data point than $\frac{1}{5}$.
- $\text{var}\left(\text{child}\right)$$ - Variance of child node.
