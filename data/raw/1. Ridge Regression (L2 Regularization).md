# Purpose

    This is used to reduces overfitting. We use this model when our straight line passes through all the train data as it creates overfitting when we introduce new data. Ridge regression helps us to tune the overfitted Linear model by adding a penalty to the cost function.

**When to use - whenever overfitting condition. Training accuracy high and test accuracy low.**

# Cost function

## Linear Regression

    $J(\theta_0, \theta_1) = \frac{1}{2m} \sum_{i=1}^{m} \left( h_\theta(x^{(i)}) - y^{(i)} \right)^2$

Where:

- $m$ = Number of training examples.
- $h_\theta(x^{(i)})$ = Predicted value for the $i^{th}$ training example.
- $y^{(i)}$ = Actual value for the $i^{th}$ training example.

## Ridge Regression

    $J(\theta) = \sum_{i=1}^{n} \left( y_i - \theta_0 - \sum_{j=1}^{p} \theta_j x_{ij} \right)^2 + \textcolor{orange}{\lambda \sum_{j=1}^{p} \theta_j^2}$

Where:

- $J(\theta) = \sum_{i=1}^{n} \left( y_i - \theta_0 - \sum_{j=1}^{p} \theta_j x_{ij} \right)^2$ ---- Represents the residual sum of squares.
- $\lambda \sum_{j=1}^{p} \theta_j^2$ ---- 1. Adds the L2 regularization penalty, which shrinks the coefficients $θj\theta_jθj$​.
- $\lambda$ ---- Hypher-parameter which _shifts global minimum and reduces Slope_. \*\*Slope will not be zero.
- $\theta_j^2$ ---- Represents _Slope_
